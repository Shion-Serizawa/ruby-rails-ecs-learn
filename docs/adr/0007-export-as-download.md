# ADR-0007: エクスポートはメール送信ではなく直接ダウンロード

- 状態: 採用 (当初の「メールで送る」方式を置き換え)
- 日付: 2026-11-05

## 背景

最初は「聴講メモを Markdown にしてメールで送る」機能だった。これは Active Job / Solid Queue /
Action Mailer を一通り試すための題材で、使い勝手から選んだものではなかった。

## 決定

`GET /conferences/:id/export` で Markdown をその場で返す (`send_data`)。
ユーザー単位で 1分10回までに制限する。ファイル名は日本語のカンファレンス名をそのまま使う。

## 検討した他の案

| 案 | 採用しなかった理由 |
| --- | --- |
| メール送信のまま | 生成はカンファレンス1件分で軽く、非同期にする必要がない。メールを経由すると受け取りが手間 |
| 両方用意する | 使われない機能のコードが残る |

## 結果

- 良い: すぐ手元に保存できる。メールの送信数を消費しない
- 注意: 非同期処理の学習題材は、パスワードリセットのメール送信と定期ジョブ (期限切れセッションの削除) で引き続き触れられる
